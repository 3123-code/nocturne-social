# 🌙 Nocturne — Your Social World, Reimagined

**Connect privately. Share freely. Stay in the moment.**

Nocturne is a social media platform built for connecting with friends, discovering short-form videos, chatting privately, and creating communities. From encrypted conversations to endless reels, Nocturne brings your social world together in one place.

🔗 **Live Website:** https://3123-code.github.io/nocturne-social/

## ✨ Features

- 💬 **Private Messaging** — Chat with your friends and keep conversations organized.
- 🔐 **End-to-End Encryption (E2EE)** — Designed to protect private conversations so only the intended participants can read them.
- 🎬 **Reels** — Scroll through short-form videos and discover content.
- 👥 **Groups** — Create groups, bring people together, and build communities.
- 🗃️ **Archived Chats** — Archive conversations to keep your inbox clean without losing track of them.
- 🤝 **Add Friends** — Find people, send friend requests, and expand your social circle.
- 🌐 **Social Connections** — Keep up with friends and interact with your community.
- 🌙 **Nocturne Experience** — A social space designed around communication, discovery, and connection.

## 🐛 Bug Reports & Feedback

**Found a bug? Please report it!**

Bug reports help improve Nocturne's stability, security, and user experience. If something does not work as expected, let us know.

When reporting a bug, please include:

- **Bug description:** What went wrong?
- **Steps to reproduce:** How can we reproduce the issue?
- **Expected behavior:** What should have happened?
- **Actual behavior:** What happened instead?
- **Environment:** Browser, operating system, and device.
- **Screenshots or recordings:** Include them when helpful.

Please report security vulnerabilities privately rather than posting exploitable details publicly.

**Your feedback matters. Every report helps improve Nocturne.**

## 🔒 Privacy & Security

Privacy is an important part of Nocturne's vision.

The platform aims to support secure communication through end-to-end encryption. Properly implemented E2EE ensures that message contents can be read only by the intended participants, not by the service operating the platform.

Security depends on the actual implementation, including encryption key management, device security, backups, and group messaging.

**Note:** The E2EE description represents the intended security model. Verify the implementation before relying on it for sensitive conversations.
